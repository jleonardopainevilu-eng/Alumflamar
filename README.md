# Alumflamar - Sitio web

Sitio web para servicios de fabricación e instalación de ventanas PVC/Aluminio, puertas Protex, muro cortina y puertas automáticas.

## Estructura
- `index.html` — página principal
- `css/style.css` — estilos
- `js/main.js` — lógica del formulario de cotización (WhatsApp)
- `images/` — fotos reales de instalaciones y logo

## Cómo publicar
Cualquier hosting de archivos estáticos sirve: Vercel, Netlify, GitHub Pages, etc.
